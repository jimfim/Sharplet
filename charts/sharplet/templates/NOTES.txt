sharplet is installed.

1. Watch the virtual node appear (label type=virtual-kubelet):

    kubectl get nodes -w
    kubectl describe node sharplet   # address should be the pod IP, not 127.0.0.1

2. Schedule a pod on the virtual node (see test.yaml in the Sharplet repo for a sample):

    kubectl apply -f test.yaml
    kubectl get pods -w             # the pod reports Running on node sharplet (spoofed by the mock provider)

3. Poke the kubelet API (plain HTTP, no client cert):

    kubectl port-forward svc/{{ include "sharplet.fullname" . }} 10255:10255
    curl localhost:10255/livez
    curl localhost:10255/containerLogs/default/<pod>/<container>

The 10250 kubelet API (client-cert TLS) is what the API server dials; it is exposed by the
service for completeness but needs a valid client certificate.
